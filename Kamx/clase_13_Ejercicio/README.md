# Clase 13 Ejercicio

React y Vite con la estructura de Clase_12_API.

```sh
npm install
npm run dev
```

En PowerShell puedes usar `npm.cmd` si `npm.ps1` está bloqueado.

- Header incluye Menu con Inicio, Hombres y Mujeres, sin lógica de navegación ni filtros.
- Main consulta https://thronesapi.com/api/v2/Characters y muestra CardCharacter.
- Footer muestra el nombre de la clase.

Los datos y las imágenes requieren conexión a Internet.

Para compilar: `npm run build`.
