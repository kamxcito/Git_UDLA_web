PSEUDOCLASE

El estado o la condición

Selecciona un elemento cuando cumple una condición: tiene el cursor encima, está marcado o es el primero de una lista.

button:hover
::

PSEUDOELEMENTO

Una parte del elemento

Da estilo a una parte, como la primera letra, o genera contenido antes o después del contenido del elemento.

p::first-letter

01 / ESTADOS Y CONDICIONES

Pseudoclases

Se escriben con :

El elemento ya existe. La pseudoclase decide cuándo se aplica el estilo.

01Interacción

Un botón que responde

:hover :active

Acá se aplica :hover al botón: se vuelve morado al pasar el cursor. Con :active cambia a rosa mientras lo mantienes presionado.

Prueba: pasa el cursor y mantén presionado el botón.

.interaction-button:hover { background: #6d42d8; }
.interaction-button:active { background: #be185d; }
02Posición

El primero y el último

:first-child :last-child

En esta lista de botones, el primero es morado y el último es verde porque ocupan esas posiciones entre los hijos de su contenedor. Los del centro conservan su estilo base.

Observa: el color depende de la posición del botón.

.position-buttons button:first-child { background: #6d42d8; }
.position-buttons button:last-child { background: #16735a; }
03Patrones

Una lista con ritmo

:nth-child(odd) :nth-child(even)

Acá se pintan las filas según su posición: las impares (odd) son moradas claras y las pares (even) son verdes claras. El conteo empieza en 1.

  1. HTML · posición impar
  2. CSS · posición par
  3. JavaScript · posición impar
  4. Accesibilidad · posición par

Observa: el patrón se repite cada dos elementos.

.striped-list li:nth-child(odd) { background: #eee8ff; }
.striped-list li:nth-child(even) { background: #e1f3ea; }
04Enfoque

El campo tiene tu atención

:focus :focus-within

El campo recibe un borde morado con :focus. Su contenedor también cambia de fondo gracias a :focus-within, porque contiene un elemento enfocado.

Prueba: entra al campo y luego haz clic fuera de él.

.focus-panel input:focus { border-color: #6d42d8; }
.focus-panel:focus-within { background: #eee8ff; }
05Selección

Marca y mira el cambio

:checked

Cuando marcas la casilla, :checked selecciona el control. El combinador + permite dar estilo al texto que está justo después: se vuelve verde y aparece tachado.

Prueba: marca y desmarca la casilla.

.check-task input:checked + span {
    color: #16735a;
    text-decoration: line-through;
}
06Disponibilidad

No todos están habilitados

:enabled :disabled

El primer botón está habilitado y recibe el color morado. El segundo tiene el atributo HTML disabled: no se puede activar y CSS lo muestra gris con :disabled.

Prueba: usa Tab; el botón deshabilitado se omite.

.availability-buttons button:enabled { background: #6d42d8; }
.availability-buttons button:disabled { background: #e4e4e7; }
07Validación

¿Tiene formato de correo?

:valid :invalid

El navegador comprueba el formato gracias a type="email". Si el valor es válido, el borde es verde; si es inválido, es rojo. Esto comprueba el formato, no que la dirección exista.

Compara «hola» con «hola@ejemplo.com». No se envían datos.

El campo vacío queda neutro usando :not(:placeholder-shown).

.validation-demo input:not(:placeholder-shown):valid {
    border-color: #16735a;
}
.validation-demo input:not(:placeholder-shown):invalid {
    border-color: #c0394b;
}
08Exclusión

Todos, excepto uno

:not()

Acá :not(.especial) selecciona los elementos que no tienen la clase especial. Por eso HTML y CSS tienen fondo morado claro; el elemento excluido conserva el fondo blanco.

HTMLCSSEspecial · excluido

Observa: :not() excluye lo que coincide con su argumento.

.tags-demo span:not(.especial) {
    background: #eee8ff;
    color: #5930b5;
}
09Navegación

El destino también tiene estilo

:target

Al seguir este enlace, la URL termina en #mensaje-destino. El elemento con ese identificador coincide con :target y se resalta con un fondo morado claro.

Resaltar el mensaje ↗

Soy el destino del enlace. Mi estilo cambia cuando mi ID aparece en la URL.

Quitar el resaltado

Prueba: activa el enlace y después quita el resaltado.

#mensaje-destino:target { background: #eee8ff; border-color: #6d42d8; }

02 / PARTES Y CONTENIDO GENERADO

Pseudoelementos

Se escriben con ::

Ahora elegimos qué parte del elemento queremos decorar.

10Contenido generado

Antes y después del texto

::before ::after

La línea de la izquierda se genera con ::before y el punto de la derecha con ::after. Son adornos creados en CSS usando content; no son etiquetas extra en el HTML.

Texto original en HTML

Observa: ambos adornos usan content: "" y un fondo de color.

.generated-label::before {
    content: ""; width: 24px; height: 3px;
    background: #6d42d8;
}
.generated-label::after {
    content: ""; width: 10px; height: 10px;
    background: #16735a; border-radius: 50%;
}
11Tipografía

Una inicial protagonista

::first-letter

Acá solo la primera letra del párrafo es más grande y morada. El resto del texto mantiene su tamaño. No hizo falta encerrar la letra en una etiqueta adicional.

Cada detalle cuenta. Con un pseudoelemento, la primera letra de este párrafo se convierte en una inicial destacada, como en el comienzo de un libro.

Observa: solo la «C» recibe este estilo.

.drop-cap::first-letter {
    font-size: 3.4rem;
    color: #6d42d8;
}
12Tipografía

La primera línea se distingue

::first-line

La primera línea visible del párrafo es verde y está en negrita. No equivale a la primera oración: las palabras seleccionadas dependen del espacio disponible.

Esta primera línea tiene algo especial. Si cambias el ancho de la ventana, verás que cambia la cantidad de palabras que reciben el estilo. CSS sigue la línea que el navegador dibuja.

Prueba: cambia el ancho de la ventana.

.first-line-demo::first-line {
    color: #16735a;
    font-weight: 700;
}
13Selección de texto

Tu selección, otro color

::selection

Cuando seleccionas una parte de este párrafo, el texto seleccionado tiene fondo morado y letras blancas. El estilo se aplica a la selección, no a todo el párrafo.

Selecciona estas palabras arrastrando el cursor. En una pantalla táctil, mantén presionado el texto y ajusta la selección. ¡Ahora puedes ver ::selection en acción!

Prueba: selecciona algunas palabras de este recuadro.

.selection-demo::selection {
    background: #6d42d8;
    color: white;
}
14Formularios

Una pista dentro del campo

::placeholder

La pista que aparece cuando el campo está vacío se pinta de morado y en cursiva. Al escribir, desaparece y tu texto usa el estilo normal del campo.

Prueba: escribe algo y bórralo para volver a ver la pista.

.placeholder-demo::placeholder {
    color: #7656a5;
    font-style: italic;
}
15Listas

Las viñetas tienen su estilo

::marker

Acá se cambia el color y el tamaño de las viñetas con ::marker. El texto de cada elemento sigue con su estilo original: el selector solo afecta al marcador.

  • Inspecciona el elemento
  • Encuentra su selector
  • Experimenta con los estilos

Observa: las viñetas son moradas; el texto no.

.marker-list li::marker {
    color: #6d42d8;
    font-size: 1.4em;
}
{ }

Ahora te toca experimentar

Abre style.css, busca el selector de un ejemplo y cambia sus colores o tamaños. Recuerda: : selecciona por estado o condición y :: da estilo a una parte o genera contenido.
